# 🛠️ フルスタック技術検証・プロトタイプ道具箱（My IT Toolbox）

本リポジトリは、これまでの30年のエンジニアキャリア（組込み・物理シミュレーション）と、モダンIT技術（Webフロントエンド、バックエンド、ネットワークインフラ）を融合させる過程でスクラッチ構築した、 **実務直結型の検証スクリプトおよびプロトタイプ集** である。
コードの断片だけではなく、「動くトイモデル」として確認するための資産群である。

## 💡 本リポジトリの構築思想：チームの生産性向上と自律的探求

本リポジトリに格納されている資産は、大きく2つの強い動機から編纂されている。
1. **現場の非効率を排除する「リファレンスモデル」としての共有:**
インフラ構築や自動化において、「毎回同じコマンドや設定を調べて一から入力する」という非効率なアプローチに陥りがちなメンバー、あるいは日々のカリキュラムの手順で手一杯になっている初学者に向けて、「手順を仕組み化し、最短でUI/UXを具現化するための動く教科書（紹介サンプル）」として自らスクラッチから構築・提供したものである。
2. **飽くなき技術的好奇心による自律的インプット（合間の3D検証）:**
カリキュラムの枠に囚われず、自身の物理シミュレーションのバックボーンをモダンWebへ射影するため、開発の合間を縫って趣味として自律的に調査・構築した3D空間レンダリングの検証モデルを格納している。

---

## 📂 資産トポロジーと検証ログ

### 1. 🌐 ネットワーク・インフラ自動化レイヤー（`/Linux_script`, `/TeraTerm_macro`）

実務現場（FAやネットワーク構築）でのオペレーションミスをなくし、手順を「仕組み化」するための低レイヤー自動化アセット群。
- **Linuxインフラ制御** (`/Linux_script`)
  - `endp0s3_down.sh` / `endp0s3_up.sh`: 演習環境における名前解決の競合をデバッグするため、特定のNICをコマンドラインから動的に制御・排他する実証スクリプト。毎回コマンドを調べる工数を根絶する。

- Cisco/SSH自動化マクロ (`/TeraTerm_macro`)
  - `ciscologin1.ttl` 〜 `ciscologin4.ttl` ネットワーク実務において、ルーターやスイッチへの連続ログイン・設定流し込みの工数を削減し、オペレーションミスを排除するためのインフラ自動化スクリプト。

### 2. 📦3Dグラフィックス＆空間表現検証（`/3Dmodel`）

物理シミュレーション（プリポスト作成）の数理的素養を、モダンWeb（WebGL）へ射影するための、趣味と探求から生まれた検証空間。
- **Three.js & Model-Viewer** (`/Threejs`, `/model-viewer`)
  - 外部の `.glb` 3Dモデル（Box, cat, WaterBottle等） をブラウザ上に軽量かつ正確に描画（レンダリング）するためのコンテキスト制御。
  - 3D空間のカメラワーク、ライティング、マテリアル表現の検証モデル。

### 3. ⚡ JavaScript UI/UX・アニメーション品評エンジン（`/javascript_sample`）

日々の課題で手一杯な初学者へ「UIの引き出し」を紹介・共有するために構築した、主要UIライブラリの比較。
- **Anime.js検証** (`/anime`, `/anime2`): タイムライン制御によるインタラクティブな動的UXのトーイモデル。

- **スライダーライブラリの3大比較** (`/slider`):
  - `slick` / `splide` / `swiper` の3種を同一要件で実装し、DOM負荷、モバイルでの追従性を比較評価。

- **ゲーム物理基礎** (`/mario`, `/Boll`, `/Block`): 2D Canvas上におけるオブジェクトの衝突判定や、簡易的な物理挙動（弾性・重力）のJavaScriptによる純粋アルゴリズム実装。

### 4. 🐘 バックエンド＆データモビリティ（`/PHP_sample`）

- 画像アップロード検証 (`/imgput`): `upload.php` によるマルチパートデータのバイナリストリーム制御、およびサーバー側バリデーションの検証モデル。

## 🎯 本リポジトリが意図するアーキテクトのコアスキル

1. **「仕組み化」による生産性向上:** コマンドの打ち直しや再調査という「無駄」を徹底的に排除し、バッチファイルやスクリプトとして共通資産化する実務能力。
2. **周囲を牽引する高いギブの精神:** 自分の知識を自分だけのものとせず、周囲が躓かないための道標（サンプル）として即座にアウトプットできるリーダーシップ。
